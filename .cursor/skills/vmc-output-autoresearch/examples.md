# VMC Output AutoResearch Examples

## Growth Site

Trigger:

```text
Use output autoresearch to rebuild the PLX public website as a growth site.
Mode: iterate-to-gate.
```

Run outline:

1. Classify archetype as `growth-site`.
2. Research SEO, competitors, ads, personas, proof points, and claim safety.
3. Synthesize sitemap, messaging, CTA model, and page plan.
4. Implement approved pages.
5. Evaluate route integrity, SEO, accessibility, performance, conversion, and
   claim safety.
6. Polish only weak gates.
7. Handoff evidence and launch risks.

## Technical Architecture

Trigger:

```text
Run output autoresearch on multi-tenant SharePoint sync architecture.
Mode: report-only.
```

Run outline:

1. Classify archetype as `technical-architecture`.
2. Read existing docs, code, and integration constraints.
3. Research comparable patterns and Microsoft Graph constraints.
4. Produce current state, target state, data flow, trade-offs, rollout plan, and
   rollback plan.
5. Evaluate evidence grounding, boundary clarity, security, migration safety,
   and verification plan.

## Competitive Intel

Trigger:

```text
Run output autoresearch on personal-care contract manufacturing competitors.
Mode: report-only.
```

Run outline:

1. Classify archetype as `competitive-intel`.
2. Define competitor set and comparison dimensions.
3. Gather source evidence.
4. Produce opportunity map and recommended moves.
5. Evaluate source quality, consistent comparison, and actionability.
